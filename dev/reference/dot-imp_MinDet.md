# MinDet: per-column quantile imputation

MinDet: per-column quantile imputation

## Usage

``` r
.imp_MinDet(x, args = list())
```

## Arguments

- args:

  list with optional `q` (default 0.01) Delegated to `MsCoreUtils`,
  which gives identical results (Bioconductor review, \#186); this
  wrapper keeps NADIA's argument names.
