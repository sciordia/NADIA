# MinProb: Minimum Probability imputation (imputeLCMD)

MinProb: Minimum Probability imputation (imputeLCMD)

## Usage

``` r
.imp_MinProb(x, args = list())
```

## Arguments

- args:

  list with optional `q` (default 0.01), `tune.sigma` (default 1)
  Delegated to `MsCoreUtils`, which gives identical results
  (Bioconductor review, \#186); this wrapper keeps NADIA's argument
  names.
