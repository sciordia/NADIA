# Run Mfuzz clustering

Run Mfuzz clustering

## Usage

``` r
run_mfuzz_clustering(eset_std, c, m)
```

## Arguments

- eset_std:

  Standardised ExpressionSet

- c:

  Number of clusters

- m:

  Fuzziness parameter

## Value

Mfuzz clustering object

## Details

The initial partition is drawn from the caller's RNG.
