# Classify proteins for all comparisons

Classify proteins for all comparisons

## Usage

``` r
.classify_all_comparisons(de_res, ev, alpha, lfc_thr, p_col)
```

## Arguments

- de_res:

  Data frame with DE results

- ev:

  Data frame with expected values

- alpha:

  Significance threshold

- lfc_thr:

  Log fold-change threshold

- p_col:

  P-value column name

## Value

Data frame with classification columns for all comparisons
