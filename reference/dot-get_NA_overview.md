# NA overview for a SummarizedExperiment

NA overview for a SummarizedExperiment

## Usage

``` r
.get_NA_overview(se, assay_name = "log2")
```

## Arguments

- se:

  SummarizedExperiment

- assay_name:

  Assay name to evaluate (default: "log2")

## Value

Data frame with NA statistics per sample
