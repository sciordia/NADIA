# Run Mfuzz clustering

Run Mfuzz clustering

## Usage

``` r
run_mfuzz_clustering(eset_std, c, m, seed = 42)
```

## Arguments

- eset_std:

  Standardised ExpressionSet

- c:

  Number of clusters

- m:

  Fuzziness parameter

- seed:

  Seed for reproducibility

## Value

Mfuzz clustering object
