# Export ggplot2 chart to PNG

Export ggplot2 chart to PNG

## Usage

``` r
.export_gg_plot(gg, filepath, width = 10, height = 7, dpi = 300)
```

## Arguments

- gg:

  ggplot2 object

- filepath:

  Full file path

- width:

  Width in inches (default: 10)

- height:

  Height in inches (default: 7)

- dpi:

  Resolution (default: 300)
