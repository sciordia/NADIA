# Export data frame to TSV and/or Parquet

Export data frame to TSV and/or Parquet

## Usage

``` r
.export_data(data, filepath_base, format = "tsv")
```

## Arguments

- data:

  Data frame to export

- filepath_base:

  Base path without extension

- format:

  "tsv", "parquet", or "both"

## Value

Invisible NULL
