# PI: Perseus-style imputation (down-shifted normal distribution)

PI: Perseus-style imputation (down-shifted normal distribution)

## Usage

``` r
.imp_PI(x, args = list())
```

## Arguments

- args:

  list with optional `width` (default 0.3), `downshift` (default 1.8)
  and `seed` (default 1234, for reproducibility of rnorm).
