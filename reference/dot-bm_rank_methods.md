# Rank methods by descending metric value

Rank methods by descending metric value

## Usage

``` r
.bm_rank_methods(agg_df, metrics)
```

## Arguments

- agg_df:

  Aggregated data.frame (one row per Assay)

- metrics:

  Character vector of metric column names

## Value

data.frame with rank columns and rank_final, sorted by rank_final
