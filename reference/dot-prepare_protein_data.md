# Prepare protein data from proteomics_data object

Prepare protein data from proteomics_data object

## Usage

``` r
.prepare_protein_data(preprocessing)
```

## Arguments

- preprocessing:

  A `proteomics_data` object, from any of the preprocess\_\*() functions

## Value

Data frame with columns: ProteinGroups, GeneNames, UniqPepts, and
intensity columns
