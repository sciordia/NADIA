# Order Method as factor (consistent with Normalization_Metrics.R pattern)

Order Method as factor (consistent with Normalization_Metrics.R pattern)

## Usage

``` r
.im_method_factor(df, method_levels)
```

## Arguments

- df:

  data.frame with Method column

- method_levels:

  Character vector of method names in desired order

## Value

data.frame with Method as ordered factor
